# `chinese-comments` 技能

## 功能与入口

当前仓库中的技能入口为 `.agents/skills/chinese-comments/SKILL.md`。技能用于为 C#/.NET 代码补全或审查简体中文 XML 文档注释，要求保持业务行为、成员签名和公开契约不变。

在能够读取仓库 Agent Skill 的环境中，要求 Agent 按该技能检查明确指定的 C# 文件。例如：

```text
请按仓库的 chinese-comments 技能审查本次修改的 C# XML 注释，只报告问题，不改代码。
```

补全与审查模式不同：审查只报告问题；补全只改用户指定范围内缺失、错误、重复或过时的注释。未指定路径时优先检查当前 Git 改动中的 C# 文件；没有可确定范围时应先询问，不默认扫描整个仓库。

## 实现、依赖与限制

规则全文和技能元数据保存在 `.agents/skills/chinese-comments/SKILL.md`，当前仓库不需要 Node.js 包或运行时脚本来读取规则。技能覆盖 XML 标签、继承注释、异步返回语义、XML 转义、编码和生成代码排除规则；它不负责改变实现、API 或运行时行为。

当前仓库没有可核实的外部技能源、安装器或向其他项目/用户目录安装的脚本。外部安装流程：待实现/待确认。不要依赖仓库外的固定磁盘路径，也不要假定 Codex、Copilot、Antigravity 或其他 CLI 支持未在本仓库确认的刷新或安装命令。
