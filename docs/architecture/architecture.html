1分层架构与依赖方向

依赖严格单向：Npoi → Core → Abstractions。NPOI 类型（IWorkbook / ISheet / ICell）不出现在任何公共契约中，这是「Provider 可替换」的全部实现手段。

2映射配置优先级与 Plan 编译流水线

四级来源经唯一合并算法收敛，再由 Plan 编译器固化为不可变计划并入缓存。任何上游模块都不得自行合并配置。

独立快照，修改输入集合并不影响已构建的映射。 MappingProfileRegistry 唯一键 = (ProfileName, Direction, ModelType)，重复注册直接抛异常，不由 DI 注册顺序覆盖；方向缺失不静默回退。

3Excel 导入数据流

11 步严格时序。注意：输入被完整复制进 MemoryStream 后才建立 DOM，MaxInputBytes 保护的是原始输入字节，不等于解压后 DOM 峰值保护。

4Excel 导出数据流

S1–S7 严格时序。ExportToFile / ExportToFileAsync 在 S1–S7 之外包裹原子提交；直接写调用方 Stream 不提供回滚保证。

5文件原子提交

IFileExportCommitter → DefaultFileExportCommitter → AtomicFileCommitter。注意最终提交点的第二次取消复查 —— 这是「取消不损坏已有目标文件」的关键。

6缓存、并发与资源防护

引擎共享状态基本并发安全，但 ExcelMappingPlanFactory 注册为 Singleton，其缓存为进程级共享。
