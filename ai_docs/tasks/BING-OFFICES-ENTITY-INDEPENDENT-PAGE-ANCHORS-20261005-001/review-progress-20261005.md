### FIX-005：Footer 内容可生成导入无法接受的重复 marker

- 严重程度：HIGH；处理要求：MUST_FIX。
- 问题：PageFooter 的普通单元格可以在同一扫描列产生第二个 marker，导出没有拒绝，但导入会拒绝自身生成的工作簿。
- 静态触发示例：PageBreak(2).PageFooter("SIGN", footer => footer.Cell("A2", "SIGN"))，配一个明细及最终 Footer。
- 证据：ExcelEntityListFooterBuilder.cs:239 只保留相对 A1；A2 合法。NpoiEntityExportExecutor.cs:1045 和 ClosedXmlEntityLayoutExecutor.cs:2167 逐项求值写入，没有 Footer 内容 marker 校验。ExcelEntitySubtotalImportScanner.cs:107 扫描全部行的 Footer marker，第二个 marker 的占用与前一个重叠，随后报配置错误。
- 影响：导出可成功、同布局导入失败。A2 工厂返回 SIGN，以及页眉/其它辅助内容产生扫描列标记的组合也需明确验证。
- 修复目标：统一保留 marker 文本的导出与导入语义，在目标流序列化前拒绝非法内容，避免修改旧输出。
- 修复要求：复用当前暂存/观察路径，不额外求值工厂两次；同时覆盖固定文本和工厂、三格式及成功非冲突场景，不扩大为任意列禁止同名业务文本。
- 验证方式：职责级真实工作簿测试断言异常类型、阶段、原始 Sheet/行列、旧输出/模板保全和观察一次；本轮仅完成静态调用链核查，未运行触发夹具。
