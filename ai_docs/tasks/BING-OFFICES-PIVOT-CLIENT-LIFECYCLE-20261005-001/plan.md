步骤：

1. net6.0/net8.0 分别从隔离 NuGet 缓存执行夹具生成，仓库现有消费者验证路径继续保留。模型采用仓库公共映射，生成明确来源和透视定义；同步/异步产物分别生成。

3. Excel 脚本创建自己的隐藏实例，禁用宏、链接更新及交互提示；只打开本任务生成文件。读取完整来源、缓存来源和全部透视结果，记录 Excel 实际版本、首次显示、打开前后刷新属性及原始矩阵。

依赖：SOURCE 阶段收口后的新鲜包。验证沿用 `dotnet restore --configfile ... --packages ...`、`dotnet run ... --no-restore -p:UseSharedCompilation=false`；脚本使用 PowerShell UTF-8 控制台和显式 UTF-8 文件输出，ps1 为 CRLF。C# 为 BOM/LF。

风险：COM 或许可证不可用、客户端可能产生本地化标签、Excel 可能修复无效文件。完整矩阵与语义字段分别核对；不通过跳过断言掩盖差异。

验收：两个 TFM 的 Provider 夹具完整且一致；可用 Excel 环境中首次打开、显式刷新及保存重开均有成功结果证据。若不可用，记录实际异常、环境缺口并继续不依赖客户端的资源任务，保留客户端验收未完成。
