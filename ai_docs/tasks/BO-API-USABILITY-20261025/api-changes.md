## 兼容说明

- AddBingOfficesCore 提供用户入口；原 Provider SPI 与 AddBingOfficesNpoi 保留。
- 单表六入口是 Workbook Request 的薄封装；现有 IExcelImporter 无新增接口成员。
- CSV/Workbook 原构造器及所有旧属性保留；新 IsComplete/StopReason 表示结构或限制摘要。Workbook 原 IsSuccess 表达式保持不变；手工构造矛盾旧结果时应结合 IsComplete 判断。
- StopAtFirstEmptyRow、MaxReadColumns=100、模板 leaveOpen=false 均保持原行为。
- 修复唯一运行差异：MaxRows 恰在 Sheet 边界耗尽时，为尚未执行的后续 Sheet 返回 ResourceLimit，避免静默成功。
