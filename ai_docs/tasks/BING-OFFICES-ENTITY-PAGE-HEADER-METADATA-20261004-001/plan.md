# Entity 重复页眉元数据复制边界

Task ID：`BING-OFFICES-ENTITY-PAGE-HEADER-METADATA-20261004-001`

## 范围

完成前阶段 DESIGN-003；不新增公开 API，不改变普通 Entity 列表、单页模板和打印标题模式。

## 契约

- 多页实际页眉复制普通值、公式文本、单元格样式（含锁定状态）、行高、隐藏状态及源区域完整包含的合并。
- 源区域内有富文本、超链接或批注时，多页导出在写目标前返回带源坐标的结构化配置错误，避免静默降级。
- 数据校验或条件格式的任一应用范围与源区域相交时，多页导出在写目标前拒绝。区域规则属于工作表层级，不隐式平移或复制。
- 单页或空明细不产生页眉副本，因此保留模板原有元数据。绘图对象依旧不在复制契约中，文档明确不复制。

## 实施

1. NPOI XLS/XLSX、ClosedXML XLSX 在已有页眉目标预检处执行源元数据检查，仅当行规划包含后续页眉时触发。
2. 两个 Provider 的页眉行复制同时复制隐藏状态；锁定状态由既有样式复制路径保持。
3. 真实模板职责测试覆盖被拒绝元数据、隐藏行与锁定样式、单页保留及调用方目标流完整。更新行为文档和符号到测试映射。
4. 完成双 TFM 职责测试、Release 常规测试、本地包消费者、API 成员与身份比较、编码和差异检查；不 commit、push 或发布。

DESIGN-004～006 后续按已建议顺序推进。
